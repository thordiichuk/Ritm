# «Ритм» — правила роботи

## Спілкування
- Відповідати українською.
- Власниця проєкту вчиться під час роботи: нові поняття (git, CI, PR, бекенд, токен тощо) пояснювати коротко, але докладно, як для новачка.

## Злиття PR
- PR можна зливати самостійно, щойно всі перевірки CI зелені (дозвіл власниці). Після злиття дочекатися деплою на GitHub Pages і перевірити живий сайт: https://thordiichuk.github.io/Ritm/
- Із червоними перевірками не зливати; спершу знайти й виправити причину.
- PR створювати, коли робота готова й перевірена.

## Перед комітом
- `npm run typecheck`, `npm test` (юніт), `npm run test:e2e` (наскрізні; знімки екрана локально відрізняються згладжуванням — їх знімає CI).
- Якщо зміна навмисно змінює вигляд, додати `[оновити знімки]` у повідомлення коміту: CI перезніме знімки й закомітить їх.

## Про проєкт
- React + Vite + TypeScript, дані в localStorage (`src/data/store.ts`), hash-маршрути.
- Дві теми: темна (за замовчуванням) і «Блакитна квіткова»; кольори лише через змінні з `src/styles/tokens.css`.
- Синхронізація через Supabase: `src/sync/`, схема бази — `supabase/schema.sql`. Публічний ключ лежить у `src/sync/config.ts`; секретні ключі в код не класти ніколи.
