# Тема «Нотатки» для «Ритму»

Еталон: `mockups/today.html`, `habits.html`, `week.html`, `phone-today.html`.
Ідея: кожен день / тиждень / огляд звичок — «нотатка» на білому аркуші. Мінімум декору, жовтий акцент, системний шрифт.

## Токени (data-theme="notes")
- Шрифт: `-apple-system, BlinkMacSystemFont, "SF Pro Text", Inter, "Segoe UI", system-ui, sans-serif` (Inter з Google Fonts як запасний). Рукописні примітки — Caveat 600.
- Аркуш (основний фон): `#FFFFFF`; бічна панель: `#F6F5F1`, межа `#E3E1DA`; колонка-список: `#FFFFFF`, межа `#ECEAE3`
- Текст `#1D1D1F`; другорядний `#6E6E73`; третинний / дата-штамп `#8E8E93`
- Межі й лінії таблиць `#E5E5EA`; шапка таблиці `#FAFAF7`
- Акцент жовтий `#F2B705` (галочки, прогрес); жовтий текст/іконки `#946A00` (контраст на білому ≥ 4.5:1), іконки панелі `#C99A00`
- Виділення: вибрана нотатка у списку `#FFE9A0`; плашка «Зараз» `#FFF0B8` з підписом `#946A00`; вибрана папка `#E9E6DC`; сьогоднішня колонка тижня `#FFFBEA`, шапка `#FFF0B8`
- Позначка «зараз»: `#D93F2B`, білий текст
- Кнопка дії (таймер): `#1D1D1F`, білий текст, радіус 10px
- Радіуси: 8–12px; без тіней, без градієнтів

## Відмінності у розкладці (лише для цієї теми)
- **Комп'ютер:** три колонки: бічна панель-«папки» 230px (Сьогодні, Тиждень, Звички, Фокус, Статистика, Вхідні, Нотатки + теги) → список нотаток 320px (закріплені: Вхідні, Топ-3 тижня; нещодавні: дні) → аркуш (max-width 720–860px, по центру). На «Тижні» колонку-список сховано.
- Над аркушем — панель інструментів: Aa, чек-лист, таблиця, малюнок, пошук, поділитися, нова нотатка.
- Зверху аркуша — сірий штамп дати («12 листопада 2026 р. о 14:40»), далі заголовок 30px bold.
- **Розклад** — чек-лист: кружечок 22px (виконано — жовта заливка з білою галочкою), час сірим 48px, назва, тег категорії `#робота` жовтим текстом. Вільний час — пунктирний кружечок і сірий текст. Поточний блок — червона позначка «зараз».
- **Звички на «Сьогодні»** — такий самий чек-лист із серією праворуч сірим.
- **Трекер звичок** — проста таблиця з тонкими межами: виконано — жовте коло 14px, пропущено — сіре кільце, сьогодні — жовте пунктирне кільце.
- **Тиждень** — таблиця на 7 колонок, у клітинках міні-чек-листи (кружечки 13px), рядок підсумків унизу.
- Підсумки й показники — звичайним маркованим списком із жирними числами (без великих плиток).
- Графік фокусу — «намальований від руки» SVG жовтою лінією, підписи Caveat.
- **Телефон:** одна колонка. Зверху «‹ Сьогодні» жовтим, поділитися / ще. Виконані блоки згорнуті в рядок «5 виконано». Знизу панель інструментів (чек-лист, таблиця, камера, малюнок, нова нотатка).
- Категорії тут не заливаються кольором — їх показують теги.

Без логотипів і фірмових елементів Apple — лише загальна естетика нотатника.
